# Telegram Captcha Bot

Простой и эффективный Telegram-бот для защиты групп от спама. Бот временно ограничивает права новых участников (запрещает писать сообщения) и присылает простую математическую капчу. После правильного решения капчи пользователь получает полный доступ к чату.

## Функционал

- Ограничение прав новых пользователей при вступлении в группу.
- Отправка пользователю простой математической капчи (сложение чисел).
- Снятие ограничений при верном ответе.
- Удаление пользователя из группы (Kick) при игнорировании капчи в течение выделенного времени.
- Локальная база данных SQLite для сохранения пользователей, успешно прошедших проверку (чтобы не отправлять капчу при повторном входе).

## ⚠️ Важное примечание

Бот использует **старую версию aiogram 2.x**. Актуальная 3-я версия имеет другой синтаксис и не совместима с данным кодом без переписывания! Также для работы бота необходим установленный Python 3.8+.

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Ward1ck/CaptchaChecker-TG-Bot-.git
   cd CaptchaChecker-TG-Bot-
   ```

2. Для удобства работы создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```

3. Активируйте виртуальное окружение:
   - В Windows: `.\.venv\Scripts\activate`
   - В Linux/macOS: `source .venv/bin/activate`

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Создайте в корне проекта файл `.env` и добавьте туда токен вашего бота, полученный у @BotFather:
   ```env
   BOT_TOKEN=ВАШ_СЕКРЕТНЫЙ_ТОКЕН
   ```

6. Запустите бота командой (или откройте `run.bat` в Windows):
   ```bash
   python main.py
   ```

## Особенности работы

Бот не умеет первым писать пользователю в ЛС (ограничение Telegram). Если бот не может отправить капчу в личные сообщения участнику, он выведет в группу предупреждение с просьбой разрешить сообщения. Рекомендуется подготовить инструкцию для новых участников или адаптировать отправку капчи прямо в группу.
